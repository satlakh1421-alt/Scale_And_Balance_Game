# ⚖️ Scale And Balance Game
An engaging and educational puzzle game focused on mathematics, weight distribution, and logic. Test your problem-solving skills by balancing scales using numbers, weights, or objects!

## 🚀 Features
- **Logical Puzzle Mechanics:** Balance scales by solving equations or finding the correct weight combinations.
- **Progressive Difficulty:** Levels scale up to test more advanced arithmetic and critical thinking.
- **Interactive Gameplay:** Enjoy responsive controls and visual feedback as the scale tips and balances.
- **Clean & Lightweight:** Built for smooth performance.

## 🎮 How to Play
1. Start a new game session and examine the unbalanced scale.
2. Read the prompt or look at the given weights/numbers.
3. Place the correct items or numbers onto the scale pans to achieve perfect balance.
4. Clear levels and progress to tougher challenges!
